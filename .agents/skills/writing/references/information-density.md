# Information density

Match length to complexity, reader knowledge, and the post's practical job. Do
not turn a short point into a full tutorial or compress a complex argument until
its evidence and boundaries disappear.

- Make each paragraph add a fact, argument, decision, example, constraint, or
  necessary transition. Merge paragraphs that make the same contribution.
- Remove preambles that only announce the topic, transitions that narrate the
  outline, and recaps that repeat the preceding text.
- Use headings and lists when they materially improve navigation or comparison,
  not to manufacture structure.
- Include an example only when it makes a difficult idea concrete or enables a
  reader action.
- Keep every necessary caveat, prerequisite, limitation, and failure mode;
  place it next to the claim or step it constrains.
- Omit the conclusion when it would only recap. Keep it when it adds an
  implication, decision, next action, or unresolved boundary.

Run a loss test after drafting: remove each sentence in turn. Delete or merge it
when meaning, evidence, voice, navigation, and safe execution remain intact.
Accuracy and reader utility outrank brevity.
